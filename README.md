# Application Mobile de Gestion de Budget Personnel (2023)

Application Android développée en **Kotlin** sous **Android Studio** pour le suivi précis des dépenses et revenus, la visualisation du solde financier et l'analyse de l'historique budgétaire.

## 🛠️ Stack Technique
- **Langage :** Kotlin
- **Plateforme :** Android Studio (Android SDK)
- **Persistance :** Firebase / Stockage local
- **Architecture :** MVVM, Coroutines & Flow
- **Versionnement :** Git

## ✨ Fonctionnalités Clés
- Saisie et catégorisation des transactions (Dépenses / Revenus / Transport / Logement).
- Calcul en temps réel du solde disponible et ventilation par catégorie.
- Historique détaillé et traçabilité financière.
